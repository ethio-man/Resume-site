# Developer Resume Website

A clean, modern, single-page static resume website built with HTML, CSS, and vanilla JavaScript.

## Features
- **Responsive Design**: Works on mobile, tablet, and desktop.
- **Project Showcase**: Specific cards for featured projects.
- **Contact Form**: Uses `mailto:` for client-side email interaction.
- **Downloadable CV**: Link to PDF resume.

## Setup
1. Open `index.html` in your browser to view the site.
2. Replace `assets/resume.pdf` with your actual resume file.
3. Update specific details (Name, Email, Social Links) in `index.html`.
4. Update the email address in `js/script.js` for the contact form to work correctly with your email.

## Deployment
This project is static and can be deployed easily on:
- **GitHub Pages**: Go to Settings > Pages and select the source.
- **Netlify**: Drag and drop the `resume-site` folder into your dashboard.
- **Vercel**: Import the project/repository.

## Structure
- `index.html`: Main HTML file.
- `css/style.css`: All styles and responsive rules.
- `js/script.js`: Contact form handling and smooth scrolling.
- `assets/`: Directory for images and documents.
